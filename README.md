Consulta de fitosanitarios del registro MAPA para pistacho, almendro y frutos de cáscara, insumos ECO certificados y autorizaciones excepcionales.

Web: https://ramonalcala777-commits.github.io/fitos/

Los datos se actualizan solos los viernes y sábados a las 15:13 (hora de Madrid). Instrucciones de mantenimiento en `CLAUDE.md`.
